# 家庭 KTV：第一至第四期改善驗收

本分支僅完成程式修改；**未執行 Firestore 真實資料寫入、未部署規則、未實播 YouTube**。合併前請先測試。

## 功能與檢查
1. 在管理歌曲編輯頁輸入候選影片曲長，點擊 25%／50%／75%，應跳至對應秒數；手動判定歌詞，未核對不得自動寫為已核對。
2. 使用同歌名、歌手但不同影片 ID 快速新增，應提示比較既有版本與候選影片；取消不匯入。
3. 在編輯頁設定歌詞、完整度、內嵌狀態與備註，儲存再讀取應保留；一般批次匯入不得清除既有驗證資料。
4. 填入正式曲長與影片長度，差異超過 15 秒顯示提醒；不得自動判定為不完整。
5. 搜尋版本切換官方 MV／歌詞版／完整歌曲，驗證開啟 YouTube 關鍵字與原本點歌行為。
6. 管理員刪除歌曲後，可於「已刪除歌曲」按鈕找到並還原；一般裝置無管理操作權限。**需先部署並測試新版 firestore.rules**。
7. Shorts 分享網址顯示警示，取消確認不得新增；一般網址與 youtu.be 正常；批次資料內 Shorts 也顯示確認。
8. 從台語分類開啟快速新增，預設台語；手動改為其他語言後，確認 Firestore 內容及跨裝置分類。

## 上線安全順序
1. 在 Firebase Emulator 以 admin / authorized anonymous / unauthorized 身分測試 rules；特別測試 removed false 還原、驗證欄位型別、未授權拒絕。
2. 發布經驗證的 firestore.rules，確認已生效。
3. 合併到 main 後確認 GitHub Pages workflow deploy **completed 且 success**。
4. 管理員使用測試歌曲逐項確認；登入家人裝置再次確認正常點歌。
5. 真實歌曲 IFrame 及中文字幕仍須逐首人工核對，不能視靜態測試通過為播放驗證成功。

## 風險與限制
- iframe 播放可因原影片禁止嵌入而失敗；審核欄位只代表人工判斷，不是自動字幕偵測。
- 曲長與來源為人工輸入，差異警示不是版權/曲目一致性的判定。
- 已刪除歌曲還原需合法管理權限與線上 Firestore 規則配合。
- 資料庫端同名不同版本警告與去重不是跨管理員的全域原子唯一約束，並行修改需人工複核。
